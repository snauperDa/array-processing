# Лабораторная работа №4. Обработка массивов

## Автор

Колосков Дмитрий Викторович

## Вариант

Вариант 11

## Цель работы

Изучить устройство массивов, научиться обрабатывать матрицы, выполнять преобразования элементов и выводить результаты в требуемом виде.

## Задача

В заданной матрице **С** записать на место отрицательных элементов нули, а на место положительных — единицы. Исходную и полученную матрицы вывести в общепринятом виде.

## Входные данные

Два целых числа — количество строк и количество столбцов матрицы

## Выходные данные

- Исходная матрица, выведенная в общепринятом виде (каждая строка матрицы — с новой строки, элементы в строке разделены пробелами)
- Преобразованная матрица, выведенная в общепринятом виде (каждая строка матрицы — с новой строки, элементы в строке разделены пробелами)

## Алгоритм работы

1. Ввести количество строк и столбцов матрицы
2. Вывести исходную матрицу на экран
3. Преобразовать каждый элемент матрицы по правилу: положительные → 1, неположительные → 0
4. Вывести преобразованную матрицу на экран
5. Завершить программу

## Пример работы

Входные данные:

```text
3 3
-1 2 0
5 -3 4
0 1 -2
```

Исходная матрица 3×3:

| -1 | 2 | 0 |
|----|---|---|
| 5  | -3| 4 |
| 0  | 1 | -2|

Итоговая матрица:

| 0 | 1 | 0 |
|---|---|---|
| 1 | 0 | 1 |
| 0 | 1 | 0 |
